#### 宏常见问题（来自 support-faqs）

**Q: Tavo 支持哪些宏？**
A: 参见 Tavo宏参考部分（完整列表）。注意：
- 所有 `{{setvar}}`、`{{getvar}}` 类宏不消耗 API token
- `{{random:val1,val2,...}}` 每次生成时随机选取一个
- `{{roll:NdM}}` 在发送前处理
- EJS 宏系统需要在「聊天设置→兼容性」中启用

**Q: 模型报错怎么办？**
A: 常见模型错误及解决方案（来自 Discord #📚丨support-faqs）：
| 错误现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| API 连不上 | Key 无效/余额不足 | 检查 API Key 和余额 |
| 配置接口越来越多删不掉 | 插件历史配置冲突 | 重置插件设置或清除缓存 |
| DeepSeek v4 flash 丢格式 | 模型输出不稳定 | 检查预设/正则/世界书的格式约束 |
| 流式输出卡顿 | 网络/模型负载 | 关闭流式输出或切换模型 |
| 400 报错频繁 | 内容被模型截断 | 换破限词/换模型/token 上限不足 |
| NAI API 报错 | API 路径/参数错误 | 检查 NAI 生图配置 |
| 更新后正则失效 | 版本兼容问题 | 更新到最新版，检查浏览器缓存 |
| 开启高级渲染闪退 | 渲染冲突 | 关正则排查，逐一启用排查 |

#### 世界书设计模式（社区最佳实践）

从银晶华-全息叙事稜鏡（605msg）等热门世界书提取的设计模式：

**银晶华模式（sigtina.w.）**：
```
职责分离：
  AI 输出结构化纯数据（XML 标签）
  正则从数据中提取并渲染为 HTML
  辅助正则移除已渲染的 HTML 以优化上下文

特点：
  - 角色专属配色方案（依据上下文自适应图标系统）
  - 9格进度条（前3负面/第4中立/5-9正面）
  - 内置精确图标库
  - 全由 AI 生成（gemini-2.5-pro），人类只负责构思/测试
```

**稜鏡引擎架构**（银式系列）：
```
AI 输出 XML → 正则匹配标签 → 渲染 HTML 状态栏
  ├─ 角色状态栏（HP/MP/心情/状态）
  ├─ 玩家状态栏
  ├─ 选项系统（对话分支）
  ├─ 小总结
  └─ 对话/描述框
```

**关键原则**：
- AI 任务简化到仅输出 XML 标签，不处理渲染
- 正则负责所有格式转换和 HTML 渲染
- 辅助正则清理已渲染标记，优化 AI 上下文长度
- 全用英文标签名避免格式错误
