---
description: 智能筛选模型白名单（元数据实时评分）
---

自动获取当前可用模型的完整实时元数据，按用户偏好维度评分，筛选白名单。模型在 web/TUI 界面手动切换，不硬编码固定 model 字段（`agent.plan`/`agent.build` 仅保留 `temperature`，不写入 `model`）。

## 环境判断

先判断当前环境，只执行当前环境适用的部分：
- 笔记本（Windows）：`$env:OS` 含 "Windows" 或存在 `C:\`
- 软路由（Linux）：`uname` 返回 Linux

<!-- laptop-only -->
本命令依赖笔记本的 `scripts/model-whitelist.mjs`、`scripts/or-free-discover.mjs` 和 `C:\Users\pass\.config\opencode\` 路径，**仅适用于笔记本**。软路由上执行时跳过「执行流程」，只参考「评分规则」理解白名单逻辑。
<!-- /laptop-only -->

## 评分规则（用户偏好）

**主评分**：AA Intelligence Index（Artificial Analysis 智力指数），数据来自 OpenRouter API `benchmarks.artificial_analysis.intelligence_index`。

- 数值越高 = 模型智力越强
- 覆盖 181 个模型，交叉验证与 AA 官网 Top-20 完全一致
- 无 AA 数据的模型降级使用多维评分（见下方）

**降级评分**（无 AA 数据时）：

| 维度 | 信号 | 加分 |
|------|------|------|
| 性价比 | cost.input/output | 免费 +30；价格越低越高（20 - in×10 - out×3） |
| 智能程度 | reasoning + 命名(pro/max/ultra/opus/thinking) | reasoning +10；高端命名 +8 |
| 速度 | 命名(flash/lite/nano/mini/lightning) | +8 |
| 全模态识图 | capabilities.input.image | +12；audio/video +4 |
| 上下文 | limit.context | ≥1M +10；≥200K +6；其他 +2 |

**保留策略**（每 provider）：
1. 在用模型（配置引用 + 当前会话，含同系列前缀匹配）→ 强制保留
2. 免费模型按分数取 Top 3
3. 全模态（image 输入）按分数取 Top 5
4. 按分数取 Top 6
5. openrouter 的 `~` latest 系列 → 保留
6. OCR/专用工具模型（DeepSeek-OCR 等）→ 排除
7. **允许使用请求数据训练的模型 → 不排除，但在报告中标注 ⚠️[训练]**
8. 单 provider 上限 10 个，超出按分数截断（在用模型优先保留）

**训练模型标注**：允许使用请求数据训练的模型（如 muse-spark-1.2-contributor、mimo-v2.5-free、hy3-free、big-pickle）会出现在列表中，但标注 ⚠️[训练] 提示用户。

**输出排序**：按分数（AA Intelligence Index）降序排列，而非字母序。



## 执行流程

<!-- laptop-only -->
### 一、备份

复制配置文件到备份（用 PowerShell，注意 UTF-8 无 BOM）：

```powershell
Copy-Item "C:\Users\pass\.config\opencode\opencode.jsonc" "C:\Users\pass\.config\opencode\opencode.jsonc.bak-model-$(Get-Date -Format yyyyMMdd)"
```

### 二、获取实时元数据

**每次执行必跑两源**，确保新模型/新免费模型被及时发现：

```powershell
# 1. 本地模型列表（opencode 已配置的 provider 模型）
opencode models --verbose > "$env:TEMP\oc-models-verbose.txt"

# 2. 实时发现最新免费模型（OpenRouter API）
node "C:\Users\pass\.config\opencode\scripts\or-free-discover.mjs" > "$env:TEMP\or-free-latest.jsonl"
# stderr: 发现摘要（数量 + 识图支持）；失败时进程退出码非0

# 3. 获取 OpenRouter 完整模型数据（含 AA Intelligence Index + 单价）
curl.exe -sL "https://openrouter.ai/api/v1/models" -o "$env:TEMP\or-models-full.json"

# 4. 获取账户余额
$orKey = (node -e "const fs=require('fs');let s=fs.readFileSync('C:/Users/pass/.local/share/opencode/auth.json','utf8').replace(/^\uFEFF/,'');const a=JSON.parse(s);console.log(a.openrouter.key)") 2>&1
$dsKey = [Environment]::GetEnvironmentVariable('DEEPSEEK_API_KEY','User')
$orBal = curl.exe -s "https://openrouter.ai/api/v1/credits" -H "Authorization: Bearer $orKey" 2>&1
$dsBal = curl.exe -s "https://api.deepseek.com/user/balance" -H "Authorization: Bearer $dsKey" 2>&1
@{ openrouter = ($orBal | ConvertFrom-Json); deepseek = ($dsBal | ConvertFrom-Json) } | ConvertTo-Json | Out-File "$env:TEMP\balance.json" -Encoding utf8
```

- 若 `or-free-discover.mjs` 失败：报告"实时发现跳过，本次仅基于本地模型列表评分"，不阻塞后续
- 若 OpenRouter 完整数据获取失败：降级使用本地多维评分（不阻塞后续）
- 若余额获取失败：报告中余额显示"获取失败"，不阻塞后续
- 四源合并由下一步 `model-whitelist.mjs` 的 `--or-free` + `--or-models` + `--balance` 参数完成
- `scripts/fetch-opencode-go-docs.mjs` 已从本命令解耦（不再自动抓取额度），如需额度参考可单独运行（不影响白名单）

### 三、评分筛选

运行筛选脚本（传入配置路径 + 当前会话在用模型 + web 发现文件 + OpenRouter 数据 + 余额数据，可多个）：

```powershell
# 合并四源后评分（AA Intelligence Index 优先，训练模型标注⚠️）
Get-Content "$env:TEMP\oc-models-verbose.txt" | node "C:\Users\pass\.config\opencode\scripts\model-whitelist.mjs" "C:\Users\pass\.config\opencode\opencode.jsonc" --or-free "$env:TEMP\or-free-latest.jsonl" --or-models "$env:TEMP\or-models-full.json" --balance "$env:TEMP\balance.json" <当前在用模型>
```

- stdout：JSON 对象 `{ whitelist: {...}, balance: {...} }`（白名单 + 余额）
- stderr：评分明细（Top 模型 + 分数 + 训练标注⚠️）+ `[人工确认]` 警告
- 训练模型（muse-spark-1.2-contributor、mimo-v2.5-free、hy3-free、big-pickle）标注 ⚠️[训练]，提示"会用请求数据训练"

**人工确认**：若脚本输出 `[人工确认]` 警告（某 provider 模型多但建议保留少），列出该 provider 的全部模型，询问用户是否保留其中某些，确认后再写入。

### 四、写入配置

用 edit 工具写入 `opencode.jsonc`（**仅白名单**，不写 `agent`）：

```json
"provider": {
  "opencode": { "whitelist": ["..."] },
  "opencode-go": { "whitelist": ["..."] },
  "openrouter": { "whitelist": ["..."] }
}
```

注意：
- 只写脚本输出的 provider（没有的 provider 不写）
- 若已有 `provider` 段，只更新 `whitelist` 字段，保留其他字段
- **不修改 `agent` 段**（`agent.plan`/`agent.build` 仅保留 `temperature`，模型由 web/TUI 手动切换）
- **保留 JSONC 注释**，不删除任何 `//` 注释行
- 保持 JSONC 语法合法（无尾逗号）
- 白名单变更后通过日常同步机制同步至软路由 `/etc/opencode/opencode.json`（JSONC→JSON 去注释）

### 五、验证

1. 语法合法（用 node 去注释后解析，避免 PowerShell GBK 乱码）：

```powershell
node -e "const fs=require('fs');let s=fs.readFileSync('C:/Users/pass/.config/opencode/opencode.jsonc','utf8');s=s.replace(/\/\*[\s\S]*?\*\//g,'').replace(/(^|[^:])\/\/.*$/gm,'$1');JSON.parse(s);console.log('OK')"
```

2. 重新运行 `opencode models`，确认列表已缩短、在用模型仍在
3. 发一条消息确认当前模型仍可用

### 六、报告

输出：
- **保留的模型**（按 provider 分组 + 分数 + 训练标注⚠️）
  - 训练模型标注：⚠️[训练] = 此模型会用请求数据训练
  - 额度说明：Go 套餐模型显示月请求数（如 150,400/月），其他显示单价
- **账户余额**：
  - OpenRouter：~$X.XX（剩余/总充值）
  - DeepSeek：¥X.XX
  - Go/Zen：订阅制/按量付费（无余额 API）
- **隐藏数量**（单 provider 超10时标注"已达上限"）
- **实时发现结果**（成功/跳过）
- 若有 `[人工确认]` 项，说明处理结果

## 注意事项

- 本命令只改 `provider.whitelist`，不修改 `agent` / 不删除任何模型定义
- 若配置已有 `provider` 段，先读原文件确认结构再编辑，避免覆盖其他字段
- 当前会话在用模型从会话上下文获取（如 `opencode-go/mimo-v2.5`）
- 编辑含中文的 JSONC 用 opencode 的 read/edit 工具（原生 UTF-8），禁止 PowerShell Get-Content/Set-Content
