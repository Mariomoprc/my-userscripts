# 修复 playwright-edge MCP 计划

## 问题分析

调用 `playwright-edge_browser_*` 工具返回 "Request timed out" 错误。

**根本原因**：PowerShell 执行策略阻止 `npx.ps1` 脚本运行
```
无法加载文件 C:\Program Files\nodejs\npx.ps1，因为在此系统上禁止运行脚本
```

**已确认**：
- Edge 浏览器正在运行（PID 6504）
- Playwright MCP Bridge 扩展已安装并启用
- Token 值匹配

## 修复方案

### 方案 A：修改 PowerShell 执行策略（推荐）
以管理员身份运行：
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 方案 B：在 opencode.jsonc 中使用 cmd 调用
将 command 改为：
```jsonc
"command": ["cmd", "/c", "npx", "-y", "@playwright/mcp@latest", "--extension", "--browser=msedge"]
```

## 关键文件

- `C:\Users\pass\.config\opencode\opencode.jsonc:110-120` - MCP 配置

## 验证方法

1. 重启 opencode 后调用 `playwright-edge_browser_tabs`
2. 应返回 Edge 标签页列表而非超时错误
