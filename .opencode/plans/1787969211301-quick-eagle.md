# 任务栏不显示插件 — 根因研究结论与验证计划

## 研究结论（explore agent 逐行源码 + 本机 config 实测）

**渲染链路**（TrafficMonitor 1.86）：
```
InitInstance:1028 LoadPlugins(GetItem 0..5 收集6项) → 1031 LoadConfig(260 item_order.Init+FromString, 262 plugin_display_item.FromString)
TaskBarDlg::CalculateWindowSize:749
  第一重:767 遍历 AllDisplayItemsWithPlugins，if(plugin && plugin_display_item.Contains(GetItemId())) 才算 item_widths
         自绘项 value_width = GetItemWidthEx(优先)/DPI(GetItemWidth())
  第二重:796 遍历 item_order.GetAllDisplayItemsWithOrder()，if(IsTaksbarItemDisplayed) 才 push m_item_widths
ShowInfo:189 遍历 m_item_widths，if(!item_rect.IsRectEmpty()) 才 DrawPluginItem
DataRequired: 监控线程无条件周期调用(1562)，与显示无关
```

**关键事实**：
- `StringSet::Contains` = `std::set<std::wstring>::count`，**大小写敏感、字符精确、无 trim 中间**（CommonData.cpp）
- `plugin_display_item` 当前值（本机实测）：`BT001TIME,clash_bottom,clash_conn,clash_mode,clash_top,go2_bottom,go2_top,go_bottom,go_top,or_bottom,or_top,sys_bottom,sys_cpu,sys_mem,sys_temp,sys_top` — **含 `go_top`**
- `item_order = 0..28`（29 项，已重建），`tbar_display_item=15`（内置），`show_task_bar_wnd=true`，`plugin_disabled` 空
- 插件 `GetItemId()` 返回 `L"go_top"`（小写 ASCII），`GetItemWidthEx`/`GetItemWidth` 返回 `widthPx=90`（非 0）
- 日志：`GetItem 0..5` 被调用（6 项），`OnInitialize`/`OnExtenedInfo(EI_CONFIG_DIR)` 均触发 `EnsureItems`

**根因假设（按概率）**：
1. **`Contains` 失败（最可能）**：`GetItemId()` 运行时返回值与 config.ini 持久化 ID 存在**字符级差异**（大小写/全半角/Unicode 规范化/隐藏字符），`std::set::count` 精确匹配失败 → 第一重 767 跳过 + 第二重 `IsTaksbarItemDisplayed:1239` 返回 false → 插件项不进 `m_item_widths` → 任务栏只剩内置项。**症状完全吻合**。
2. **`plugin_display_item` 被 `SaveConfig` 覆盖**：启动 `FromString` 解析后内存 set 与 config 不一致，`SaveConfig:416` 用 `ToString()` 回写覆盖（若解析失败则清空）。
3. **width=0（次可能）**：`GetItemWidthEx` 返回 0 且 `GetItemWidth` 返回 0 → `TotalWidth=0` → rect 空 → `ShowInfo:189` 跳过。但本实现返回 90，排除（除非 `m_cfg` 为 null）。

## 验证计划（决定性，一次定位）

**步骤 1 — 部署带完整打点的 DLL（已编译 192000，含 GetItemId 打点）**
- `AILimitPlugin.cpp` 已加：`GetItemId` 每次查询写 `AILimit_debug_<PID>.log`（`GetItemId go_top`）
- 补打点：`GetItemWidth`/`GetItemWidthEx` 返回值、`DataRequired` 入口、`DrawItemEx` 的 `w/h/dark_mode`
- 编译 → `TRAFFI~1\plugins\` 覆盖（Move-Item 绕过占用）→ 高权限令牌 `Console 1` 拉起

**步骤 2 — 读日志判定**
- `GetItemId go_top` 出现 → 宿主查询 ID，`Contains` 应匹配 → 若仍不显示则查 `DataRequired`/`DrawItemEx`
- `GetItemId` 不出现 → 宿主未走到 `CalculateWindowSize` 第一重 → 查 `plugin_display_item` 是否被覆盖（重启后读 config.ini 对比）
- `DrawItemEx w=0` → width 问题；`DrawItemEx` 不出现但 `GetItemId` 出现 → `Contains` 失败（对比 `GetItemId` 输出与 config.ini 字节）

**步骤 3 — 修复**
- 若 `Contains` 失败：在 `GetItemId()` 返回前 `std::wstring` 与 config 逐字符对比，修正 ID（如大小写/编码）；或插件侧 `OnInitialize` 主动 `SetStrContained(id, true)` 写入 `plugin_display_item`
- 若 `plugin_display_item` 被覆盖：确认 `FromString` 解析（config.ini 编码 GBK 无 BOM），必要时插件 `OnInitialize` 后主动写回
